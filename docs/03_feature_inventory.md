# Feature Inventory: MCP Any

## Current Backlog (P0/P1)
- **Policy Firewall**: Rego/CEL based hooking for tool calls.
- **HITL Middleware**: Suspension protocol for user approval flows.
- **Recursive Context Protocol**: Standardized headers for subagent inheritance.
- **Shared KV Store**: Embedded SQLite "Blackboard" tool for agents.

## Evolution: [2026-06-19] Updates

### Proposed Additions
- **Hardware-Attested Intent Lineage (HAIL) Provider**: (P0) Authoritative security middleware that issues cryptographically signed "Reasoning Fragments" for all sub-instructions.
- **Hardware-Locked Attention Governance (HLAG) Provider**: (P0) Advanced attention guard that utilizes hardware-bound headers to "pin" mission-critical fragments in the context window.
- **Lock-Free Mesh Coordination (LFMC) Hub**: (P0) Coordination service implementing CRDT-based task list synchronization for parallel teammates in horizontal swarms.

### Priority Shifts
- **Active Intent-Deconstruction (AID) Hub**: (Re-affirmed P0) Now elevated with the requirement for mandatory **HAIL-attestation** for all inter-teammate messages.
- **Stylometric Mimicry Mitigator (SMM)**: (Re-affirmed P0) Evolving to support the new **Multi-Modal Behavioral Anchoring** requirement discovered today.

## Evolution: [2026-06-18] Updates

### Proposed Additions
- **Attention-Locking Middleware**: (P0) Security extension for the ContextEngine supporting `x-gemini-attention-lock` and similar headers to prevent REE-driven intent eviction.
- **Shadow Coordination Interceptor (SCI)**: (P0) Advanced security middleware for the T2T Encryption Bridge that monitors transport metadata for out-of-band subagent collusion.
- **Sovereign Shard Controller**: (P0) Advanced extension for the LFMC Hub that enforces intent-bound isolation for teammate-local shards.
