# Design Doc: HLAG (Hardware-Locked Attention Governance)
**Status:** Draft
**Created:** 2026-06-19

## 1. Context and Scope
Autonomous swarms are vulnerable to REE attacks. HLAG utilizes hardware-bound headers to cryptographically "pin" critical intent fragments in the attention tier.
