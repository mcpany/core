# Design Doc: Teammate Sovereignty Enforcer (TSE)
**Status:** Draft | **Created:** 2026-06-18

The TSE provides kernel-level isolation for parallel agent teammates, ensuring that "State Smearing" and "Logic Bombs" are prevented at the transport layer.
