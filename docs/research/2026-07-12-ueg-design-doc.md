# Universal Episodic Graph (UEG) Memory Broker Design Doc
**Author:** Lead Systems Architect (L7)
**Date:** 2026-07-12
**Status:** Draft

## 1. Objective
To evolve MCP Any’s Shared KV Store into a hardware-attested, graph-based memory structure (The Universal Episodic Graph) that resolves "Context Amnesia" and "Memory Smearing" in deep, horizontal multi-agent swarms.

## 2. Background
Current multi-agent frameworks (OpenClaw, AutoGen, Claude Code Agent Teams) pass context as linear arrays of text (e.g., messages, summaries) between subagents. This leads to two critical failures:
1.  **Context Smearing:** Malicious or hallucinating subagents pollute the shared state.
2.  **Context Amnesia:** Crucial mission-root intents are evicted from the LLM’s attention window during deep reasoning loops.

The industry is moving toward "Hardware-Attested Attention Locking" and "Multimodal State Entanglement." However, the underlying storage—the Blackboard—remains a flat KV store. We need a memory structure that understands *relationships*, *temporality*, and *provenance*.

## 3. High-Level Design
The UEG Memory Broker will replace the flat Shared KV Store with a lightweight, embedded Graph Database (e.g., an abstraction over SQLite utilizing recursive CTEs for graph traversal).

### Key Components:
1.  **Episodic Nodes:** Every reasoning trace, tool call output, and state fragment is stored as a distinct "Episode" node.
2.  **Hardware-Attested Edges:** Relationships between episodes (e.g., "Generated By", "Refines", "Contradicts") are cryptographically signed by the agent’s hardware identity (TPM) and the active Mission Root.
3.  **Semantic Vector Indexing:** Episode nodes are embedded and indexed locally, allowing subagents to query context based on semantic similarity rather than linear recency.
4.  **Zero-Knowledge Sub-graphs:** Agents can only traverse edges that are authorized by their current "Mission-Bound Token."

## 4. Detailed Architecture

### 4.1 Episodic Ingestion
When an agent completes a task or generates a reasoning trace, the UEG Middleware intercepts the Binary State Handoff (BSH).
*   **Sanitization:** The payload is processed by the Atomic Fragment Sanitizer (AFS).
*   **Node Creation:** An `Episode` node is created containing the semantic content, the agent's identity token, the timestamp, and the origin framework.
*   **Edge Creation:** The UEG Broker creates a `DESCENDS_FROM` edge linking the new episode to its parent mission-root or previous subtask, signed by the TPM.

### 4.2 Semantic Traversal & Retrieval
Instead of receiving a flat summary, a subagent queries the UEG.
*   **Query:** "Retrieve episodes related to 'database schema migration' within my current intent scope."
*   **Traversal:** The UEG Broker performs a semantic search combined with a graph traversal, ensuring it only returns nodes reachable via hardware-attested edges authorized for that subagent.

### 4.3 Multimodal Entanglement
Non-textual traces (SVG, Audio) are treated as distinct node types (`Multimodal_Episode`). They are cryptographically entangled with textual `Reasoning_Episode` nodes via a `VALIDATES` edge, preventing context smuggling where an image contradicts the text.

## 5. Security & Privacy
*   **Hardware-Bound Provenance:** Every node and edge requires a TPM signature. "Shadow Subagents" cannot inject state because they cannot produce a valid cryptographic edge linking back to the mission root.
*   **Isolation by Graph Partitioning:** Subagents operating in different horizontal teams are physically isolated in disparate sub-graphs. Without an authorized `SHARES_STATE` edge (managed by the Lock-Free Mesh Arbiter), cross-team state pollution is impossible.

## 6. Rollout Plan
*   **Phase 1 (v0.60):** Implement the embedded graph storage engine alongside the existing KV store (Shadow Mode).
*   **Phase 2 (v0.61):** Migrate the Active Intent Alignment (AIA) Broker to use UEG edges for heartbeat validation.
*   **Phase 3 (v0.62):** Expose the UEG retrieval API to connected agents via the Universal Multimodal Memory Bus (UMMB).

## 7. Metrics & Success Criteria
*   **Latency:** Graph traversal for a 10-hop intent chain must complete in < 5ms.
*   **Accuracy:** 100% elimination of "Memory Smearing" exploits in regression tests.
*   **Scale:** Support for 100,000 concurrent episodic nodes per active mission mesh without degradation in the Atomic Shard Lock-Manager.
