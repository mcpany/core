# Market Sync: 2026-04-12 (Iteration 2)

## Ecosystem Updates & Vulnerability Synthesis

### 1. Claude Code: Configuration-as-Execution Exploits
- **CVE-2025-59536**: Discovered that project-local configuration files (e.g., `.claude/settings.json`) can be weaponized to execute arbitrary code before the user even accepts the trust dialog. This highlights a critical "Pre-Flight" vulnerability where the agent ingests "hooks" as executable logic.
- **CVE-2026-21852**: Revealed an API key exfiltration vector where a malicious repository overrides `ANTHROPIC_BASE_URL` in local settings, redirecting traffic to an attacker-controlled proxy.
- **Impact**: These findings confirm that "Implicit Local Trust" is a flawed model. Agents must treat project-local metadata as untrusted, high-risk input.

### 2. Gemini MCP: Command Injection in Toolchains
- **CVE-2026-0755**: A critical vulnerability (CVSS 9.8) was identified in `gemini-mcp-tool` where the `execAsync` function constructor constructed OS commands using LLM-generated arguments without sufficient sanitization.
- **Impact**: This represents a collapse of the execution boundary. MCP tool parameters, previously seen as benign data, are now a direct RCE vector if not strictly isolated.

### 3. Agent Swarm Coordination & A2A Maturation
- **A2A (Agent2Agent) Protocol**: The transition to the Linux Foundation is consolidating the industry around a vendor-neutral standard for task negotiation.
- **Swarm Attacks (GTG-1002)**: Real-world campaigns demonstrate that AI-orchestrated intrusions can outpace human monitoring, requiring autonomous, machine-speed defense mechanisms.

## Summary of Today's Unique Findings
1. **"Settings-as-Shell" Pattern**: Configuration files are being used as a primary vector for RCE, bypassing traditional sandbox triggers.
2. **API Key Redirection**: The simplicity of overriding environment variables via local config poses a massive secret exposure risk.
3. **Parameter Privileged Input**: Tool arguments generated by LLMs must be treated with the same level of scrutiny as user-provided shell input.
4. **Demand for Deterministic Boot**: The consensus is shifting toward requiring cryptographic signatures for *all* local state before agent initialization.
