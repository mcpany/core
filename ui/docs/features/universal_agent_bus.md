# Universal Agent Bus

The Universal Agent Bus (UAB) introduces new capabilities for multi-agent workflows, managing and mapping subagents dynamically.

## Goal

Provide a robust user interface for visualizing, configuring, and orchestrating interactions between complex AI swarms.

## Key Features

- **Recursive Context Dashboard**: Visualize state inheritance and session tokens across agent swarms.
- **Multi-Agent Session Timeline**: Visual tracking of agent handoffs and shared tool state.
- **Unified Discovery Manager**: UI for managing and auto-discovering MCP servers across transports.
- **Lazy-MCP Tool Search Dashboard**: UI for managing the on-demand tool index and monitoring search hits/misses.
- **Agent Chain Tracer (A2A)**: Visual timeline of multi-agent handoffs and message passing.

## Usage

Use the specific interfaces nested under the **Universal Agent Bus** section of the navigation to monitor, approve, and manage swarms, task handoffs, and agent coordination messages.
