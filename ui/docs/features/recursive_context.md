# Recursive Context Dashboard

The Recursive Context Dashboard enables monitoring and visualizing state inheritance and session tokens across agent swarms.

## Goal

Provide full observability into subagent contexts and the information that passes between them when using the Recursive Context Protocol.

## Usage

1. Navigate to `/context`.
2. View the visual layout representing the inheritance hierarchy.
3. Drill down into specific session tokens to view variable mappings, inherited permissions, and active variables for debugging multi-agent workflows.

## Features

- Display real-time graphs showing how state maps between a parent agent and spawned subagents.
- Track usage limitations, timeouts, and specific resource allocations.
